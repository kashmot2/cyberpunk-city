# Cyberpunk City

A neon-lit cyberpunk cityscape you can explore in your browser. Walk through towering skyscrapers, crash junctions from Burnout Revenge, and a glowing skybox — all rendered in real-time with Three.js.

![Three.js](https://img.shields.io/badge/Three.js-black?logo=three.js)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## Play

**[Launch Cyberpunk City](https://kashmot2.github.io/cyberpunk-city/)**

## Features

- Cyberpunk-themed city with imported Sketchfab models
- Multiple Burnout Revenge crash junction maps
- Third-person player controller with robot character
- Futuristic skybox environment

## Tech Stack

| Tool | Purpose |
|------|---------|
| Three.js | 3D rendering & scene management |
| GLTFLoader | Loading `.glb` models |
| Sketchfab | Source for 3D assets |
| GitHub Pages | Hosting |

## Run Locally

```bash
git clone https://github.com/kashmot2/cyberpunk-city.git
cd cyberpunk-city
python3 -m http.server 8000
# open http://localhost:8000
```
